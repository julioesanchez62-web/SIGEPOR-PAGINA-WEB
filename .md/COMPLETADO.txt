## 📋 ENDPOINTS API

### VETERINARIOS
```
POST   /api/veterinarios/registrar     ← Registrarse
POST   /api/veterinarios/login         ← Iniciar sesión
GET    /api/veterinarios/perfil        ← Ver perfil
```

### VACUNACIONES
```
POST   /api/vacunas                    ← Crear
GET    /api/vacunas                    ← Obtener todas
GET    /api/vacunas/:id                ← Obtener una
PUT    /api/vacunas/:id                ← Actualizar
DELETE /api/vacunas/:id                ← Eliminar
GET    /api/vacunas/estadisticas/...   ← Estadísticas
```

### PORCINOS
```
POST   /api/porcinos                   ← Crear
GET    /api/porcinos                   ← Obtener todas
```
