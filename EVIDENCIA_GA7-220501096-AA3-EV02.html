1. Módulos desarrollados e integración

La solución se organizó por responsabilidades para facilitar mantenimiento y evolución. El backend expone una API REST y el frontend consume sus servicios mediante Axios.

Backend modular

  • src/app.js: Express y rutas.
  • src/server.js: arranque y conexión.
  • src/modules/auth: login JWT.
  • src/modules/users: CRUD y estado.
  • Repositorios, servicios, validadores y middleware.

Frontend web

  • sice-frontend/src: aplicación React.
  • Login y sesión persistente.
  • Dashboard y perfil.
  • Crear, editar, consultar y eliminar usuarios.
  • Rutas protegidas y por rol.
React + Axios→API Express→Servicios / repositorios→MySQL

Programación orientada a objetos y buenas prácticas

Aunque el código usa módulos funcionales de Node.js en lugar de clases en todos los componentes, aplica encapsulamiento por capas, separación de responsabilidades, reutilización de servicios y manejo centralizado de errores. Las credenciales se obtienen desde variables de entorno.

2. Persistencia y funcionalidades implementadas

Persistencia MySQL

  • Pool de conexiones con mysql2/promise.
  • Tablas usuario y rol.
  • Relación usuario-rol mediante clave foránea.
  • Eliminación lógica mediante deleted_at.
  • Validación de conexión con SELECT 1.

Seguridad

  • Contraseñas cifradas con bcrypt.
  • Tokens JWT con expiración configurable.
  • Middleware para proteger recursos.
  • Validación de datos de entrada.
  • Mensajes de autenticación no reveladores.
