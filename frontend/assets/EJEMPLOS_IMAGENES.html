🐷 Guía de Ejemplos de Imágenes para SIGEPOR

Esta página contiene ejemplos de código que puedes copiar y pegar directamente en tus archivos HTML.

📸 Ejemplo 1: Galería de Razas en registroporcino.html

Agrega una galería visual de razas de cerdos antes del formulario.

Código HTML:

<!-- Agregar en registroporcino.html, después del header, antes del formulario --> <div class="breed-gallery"> <div class="breed-card"> <img src="cerdos/cerdo-landrace.jpg" alt="Raza Landrace" style="width:100%; height:250px; object-fit:cover;"> <h4>🐷 Landrace</h4> <p style="padding: 0 15px 15px 15px; margin:0; font-size:0.85rem; color:#6e544f;">Raza blanca, alargada, excelente para carne</p> </div> <div class="breed-card"> <img src="cerdos/cerdo-duroc.jpg" alt="Raza Duroc" style="width:100%; height:250px; object-fit:cover;"> <h4>🐷 Duroc</h4> <p style="padding: 0 15px 15px 15px; margin:0; font-size:0.85rem; color:#6e544f;">Raza rojiza, precoz y de buen crecimiento</p> </div> <div class="breed-card"> <img src="cerdos/cerdo-yorkshire.jpg" alt="Raza Yorkshire" style="width:100%; height:250px; object-fit:cover;"> <h4>🐷 Yorkshire</h4> <p style="padding: 0 15px 15px 15px; margin:0; font-size:0.85rem; color:#6e544f;">Raza blanca, musculosa, productiva</p> </div> </div>

Visualización:

🐷

Landrace

Raza blanca, alargada, excelente para carne

🐷

Duroc

Raza rojiza, precoz y de buen crecimiento

🐷

Yorkshire

Raza blanca, musculosa, productiva

💡 Consejo: Asegúrate de que las imágenes estén en la carpeta cerdos/ con los nombres exactos: cerdo-landrace.jpg, cerdo-duroc.jpg, etc.

🖼️ Ejemplo 2: Imagen en Feature Card de index.html

Reemplaza el emoji en las tarjetas de características con una imagen real.

Código HTML Original:

<div class="feature-card"> <div class="feature-icon">🐷</div> <h3>Registro Porcino</h3> <p>Gestiona información completa de tus animales</p> </div>

Código HTML Mejorado:

<div class="feature-card"> <img src="cerdos/cerdo-feliz.jpg" alt="Registro Porcino" style="width:100%; height:200px; object-fit:cover; border-radius:12px; margin-bottom:15px;"> <h3>Registro Porcino</h3> <p>Gestiona información completa de tus animales</p> </div>
⚠️ Importante: Si usas imágenes, reduce el tamaño de la altura de 200px según sea necesario para mantener consistencia.

🔐 Ejemplo 3: Imagen en Página de Recuperación

Reemplaza la ilustración en restaurar.html con una imagen de cerdo seguro.

📊 Ejemplo 4: Imagen en Estadísticas (Avanzado)

Agrega pequeñas imágenes en las tarjetas de estadísticas.

Código HTML:

<div class="stat-card"> <img src="cerdos/cerdo-pequeño.jpg" alt="Total de porcinos" style="width:80px; height:80px; border-radius:50%; object-fit:cover; margin-bottom:15px;"> <h4>Total de Porcinos</h4> <p class="stat-number" id="statTotal">0</p> </div>
💡 Consejo: Usa border-radius:50% para hacer la imagen circular, perfecto para avatares y estadísticas.

📋 Paso a Paso: Cómo Agregar Imágenes

  1. Crea la carpeta:
    SIGEPOR/cerdos/
  2. Descarga imágenes de Unsplash, Pexels o Pixabay
  3. Renombra las imágenes con nombres claros:
    • cerdo-landrace.jpg
    • cerdo-duroc.jpg
    • cerdo-yorkshire.jpg
    • cerdo-feliz.jpg
    • cerdo-seguridad.jpg
  4. Optimiza las imágenes:
    • Máximo 500KB por imagen
    • Ancho mínimo: 800px
    • Formato: JPG o PNG
  5. Copia y pega el código HTML de este documento a tus archivos
  6. Prueba en el navegador y ajusta según necesites
