🏗️ Arquitectura SIGEPOR - SQL Integration

Capas de la Aplicación

💻 Frontend

  • index.html
  • registro_veterinarios.html
  • vacunas.html
  • HTML + CSS + JavaScript
  • Peticiones AJAX/Fetch

🔌 Backend API

  • Node.js + Express
  • server.js
  • Puerto 3001
  • JWT Auth
  • CORS habilitado

🗄️ Base de Datos

  • MySQL 8.0+
  • Base: sigepor
  • localhost:3306
  • 4 tablas
  • Relaciones FK

API Endpoints

Veterinarios

POST /api/veterinarios/registrar
Registrar nuevo veterinario
POST /api/veterinarios/login
Iniciar sesión y obtener token
GET /api/veterinarios/perfil
Obtener datos del veterinario logueado

Vacunaciones

POST /api/vacunas
Crear nueva vacunación
GET /api/vacunas
Obtener todas las vacunaciones del veterinario
GET /api/vacunas/:id
Obtener una vacunación específica
PUT /api/vacunas/:id
Actualizar vacunación
DELETE /api/vacunas/:id
Eliminar vacunación

Tablas de Base de Datos

📌 veterinarios

id, nombre, email, usuario, contraseña (hash), fecha_registro, activo

💉 vacunaciones

id, veterinario_id (FK), porcino_id, nombre_vacuna, fecha_aplicacion, estado, dosis, proxima_vacuna_dias, notas, fecha_registro

🐷 porcinos

id, veterinario_id (FK), identificacion, raza, peso, estado_salud, fecha_nacimiento, genero, fecha_registro

📋 logs_actividad

id, veterinario_id (FK), accion, descripcion, fecha_hora

Instalación Rápida

Pasos a seguir:

  • Crear BD ejecutando database.sql en MySQL
  • Instalar dependencias: npm install
  • Configurar .env con credenciales MySQL
  • Iniciar servidor: npm start
  • Abrir index.html en navegador
  • Registrarse e iniciar sesión
  • Gestionar vacunaciones

🔒 Características de Seguridad

Implementado:

  • Hash de contraseñas con bcryptjs
  • Autenticación JWT sin estado
  • CORS con control de orígenes
  • Validación en servidor y cliente
  • Foreign Key constraints
  • Índices para optimización
  • Variables de entorno para credenciales
