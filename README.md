# sice-backend

Backend del proyecto SICE con una estructura modular por funcionalidades.

## Estructura

- src/config: configuraciones de base de datos y JWT
- src/modules: módulos de autenticación, vacantes, postulaciones y usuarios
- src/middlewares: middlewares globales
- src/utils: utilidades y validaciones
- src/app.js: punto de entrada de la aplicación
